⚠️ Bạn đang mở trang web trực tiếp qua giao thức file://

Do dự án sử dụng chuẩn tách module JavaScript ES Modules (import / export), các trình duyệt web hiện đại (Chrome, Edge, Firefox) áp dụng chính sách an ninh CORS sẽ chặn không cho file nạp trực tiếp qua giao thức file:// (khi nhấp đúp file).

Cách chạy đúng (chỉ 1 thao tác):
  1. Trong Visual Studio Code: Cài đặt tiện ích mở rộng Live Server (Ritwick Dey).
  2. Nhấp chuột phải vào file index.html ➔ Chọn "Open with Live Server" (hoặc bấm nút "Go Live" ở góc dưới bên phải VS Code).
  3. Trang web sẽ tự động mở tại http://127.0.0.1:5500/index.html với đầy đủ các cột, ô số và thanh điều khiển!
  4. (Cách khác nếu có Node.js: Mở Terminal gõ lệnh npx serve).

📖 Giải thích nhanh ký hiệu độ phức tạp Big-O: O(f(n))

Ký hiệu Big-O biểu diễn tốc độ tăng của thời gian chạy hoặc bộ nhớ sử dụng khi số lượng phần tử đầu vào (n) tăng lên.

O(1) - Hằng số
Thời gian thực thi không đổi bất kể kích thước dữ liệu n lớn đến mức nào.
O(log n) - Logarit
Rất nhanh; không gian tìm kiếm giảm một nửa sau mỗi bước (như Binary Search).
O(n) - Tuyến tính
Thời gian chạy tỷ lệ thuận theo số lượng phần tử (như Linear Search).
O(n log n) - Tuyến tính logarit
Tốc độ tối ưu cho các thuật toán sắp xếp so sánh (như Merge Sort, Quick Sort).
O(n²) - Bậc hai
Thường có 2 vòng lặp lồng nhau (Bubble, Selection, Insertion Sort); chậm khi n lớn.
